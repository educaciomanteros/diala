# DIALA — Top Manta

Web del projecte DIALA: les històries passen de boca en boca.

Projecte amb infants, joves, famílies i centres educatius de Barcelona.

## Llengües

Català, castellà, francès, wòlof, àrab, italià, turc, amazic i filipí.
Les traduccions són versions de treball: cal revisar-les amb les comunitats, especialment el wòlof i l’amazic.

## Publicació amb GitHub Pages

Web estàtica sense dependències ni compilació. A Settings → Pages, seleccionar Deploy from a branch, branca main i carpeta / (root).

## Fitxers

- index.html: estructura de la web.
- style.css: disseny adaptable de brutalisme tàctil.
- content.js: contingut de les nou llengües.
- app.js: selector de llengua, activitats, preguntes i proposta descarregable.
- DIALA-projecte-catala.md: dossier original en català.

La web no envia propostes ni recull dades personals. Les propostes es descarreguen al dispositiu.
